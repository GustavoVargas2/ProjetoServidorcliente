Projeto acadêmico desenvolvido como atividade da faculdade, com o objetivo de aplicar na prática conceitos de programação e integração com banco de dados local.

O sistema permite cadastrar clientes e registrar informações sobre pontos de coleta de resíduos, armazenando os dados em um banco de dados local para consulta e gerenciamento.

Funcionalidades
Cadastro de clientes.
Registro do tipo de resíduo.
Cadastro do endereço do ponto de coleta.
Identificação do ponto de coleta pelo nome.
Armazenamento dos dados cadastrados em banco de dados local.
Objetivo
Desenvolver conhecimentos em programação, manipulação de dados e integração entre aplicações e bancos de dados, utilizando como exemplo prático o gerenciamento de informações relacionadas à coleta de resíduos.
